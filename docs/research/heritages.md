# 出自の地域設定と入力の補助

確認日：2026年10月2日。John Harper / One Seven Design の [公式Downloads](https://bladesinthedark.com/downloads) から配布される [Player's Kit v8.2](https://bladesinthedark.com/sites/default/files/blades_playerkit_v8_2.pdf#page=25) のPDF 25ページ「The Shattered Isles」をウェブで確認しました。取得原本の記録は [sources.json](sources.json) にあります。

以下はアプリ用の参考訳・要約です。地域設定は公式無料PDFを根拠とし、SRDの一般的なキャラクター作成ルールとは区別します。原文で噂として述べられている内容は、注釈でも噂として扱います。

| 地域 | 原典から確認した特徴 |
| --- | --- |
| Akoros | 帝国発祥の地。石化した暗い森と岩がちな丘。沿岸都市はリヴァイアサン狩猟と内陸の鉱山で富を得る。ドスコヴォルの所在は同PDFの23ページの都市地図でも確認できる。 |
| The Dagger Isles | 熱帯の密林に覆われる群島。大災厄の魔法で密林が暗く歪んだ。電撃障壁なしで暮らすという噂があるが、その方法は謎。 |
| Iruvia | 黒い砂漠、黒曜石の山々、活発な火山。悪魔が公然と権力を握るという噂。 |
| Severos | 低木や棘のある植物が広がる風吹く平原。沿岸の帝国都市の外では、幽霊を狩る馬と死の荒野で物資を探す自由な部族も暮らす。 |
| Skovlan | 寒冷な山と荒れたツンドラ。帝国支配に最後まで抵抗した土地。 |
| Tycheros | 帝国から隔絶した遠い土地。人々の家系に悪魔の血が流れるという噂。 |

Akorosを他地域より「文明レベルが高い」と比較する注釈は、この資料では裏付けられないため使いません。設定を想像しやすい地理・暮らし・歴史を示します。

[公式SRDのCharacter Creation](https://bladesinthedark.com/character-creation) は、Heritageを家系の出身地とし、家族の暮らしについて詳細を書くよう説明しています。アプリでは自作の記入例を「出自の詳細」のプレースホルダーに表示します。地域説明を家族全員の職業や本人の出生地を決める制約として扱いません。

編集画面の選択肢には「地域名：短い特徴」、選択後の欄には地域の説明を表示します。出自 → 出自の詳細 → 経歴 → 経歴の詳細を縦に並べ、地域の説明は欄の全幅を使います。英語PDFへのリンクは編集画面には表示せず、この調査資料に出典を残します。シートでは地域名を表示し、保存するIDと自由記入の詳細は従来どおりです。
